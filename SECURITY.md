# Security Policy

## Supported Versions

This SDK is auto-generated from Azion's public API specifications. Only the
latest released version is supported with security updates. Please ensure you
are using the most recent release before reporting an issue:
https://github.com/aziontech/azionapi-v4-go-sdk-dev/releases/latest

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them via GitHub Security Advisories:

1. Go to https://github.com/aziontech/azionapi-v4-go-sdk-dev/security/advisories/new
2. Fill out the vulnerability report form
3. Submit the report

Alternatively, you can email the Azion security team at security@azion.com.

Please include as much of the following as possible to help us triage the
report quickly:

- The affected SDK version and Go version
- A description of the vulnerability and its potential impact
- Steps to reproduce, including a minimal code sample if available
- Any known workarounds or mitigations

## Disclosure Timeline

- **Within 3 business days:** we acknowledge receipt of your report.
- **Within 10 business days:** we complete an initial assessment and let you
  know whether the report is accepted, along with an expected remediation
  timeline.
- **Every 15 days:** we provide status updates until the issue is resolved.
- **Within 90 days:** we aim to release a fix and publish a security advisory.
  We coordinate public disclosure with you and will credit you unless you
  prefer to remain anonymous.

Please do not publicly disclose the issue until we have published an advisory
or the 90-day window has elapsed.
